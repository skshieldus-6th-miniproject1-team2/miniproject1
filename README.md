#### 감정별 기사 탐색 — 표 방식으로 확정

막대 클릭 → 토글 대신 **감정 탭 + 표**를 씁니다.

- 토글은 한 번에 하나만 열려 감정 간 비교가 안 됨
- 막대 클릭은 발표 자리에서 아무도 눌러야 하는 줄 모름 (탭은 보임)
- 제목·시점·날짜·확률·원문 링크를 한 줄에 다 담을 수 있음

```python
emo = st.segmented_control("감정", ["전체"] + EMOTIONS, default="전체")
order = st.radio("정렬", ["확률 높은 순", "최신순"], horizontal=True, label_visibility="collapsed")
if st.button("랜덤 5건 뽑기"):
    view = view.sample(min(5, len(view)))
st.dataframe(
    view[["감정", "기사제목", "시기", "날짜", "수치", "url"]],
    column_config={"url": st.column_config.LinkColumn("원문", display_text="원문 ↗"),
                   "수치": st.column_config.NumberColumn("확률", format="%.3f")},
    hide_index=True, use_container_width=True,
)
```

## 계산 규칙 — 이건 바꾸지 말고 씁니다

```
# 거래 한 건
평형   = 전용면적(㎡) ÷ 3.3058
평단가 = 거래금액(만원) ÷ 평형

# 그룹(구·동·월)의 평균 평단가 — 두 방식이 있습니다
산술평균 = Σ(건별 평단가) ÷ 거래건수      ← 채택. 거래 한 건 = 1표
가중평균 = Σ(거래금액)   ÷ Σ(평형)        ← 검증용으로만 계산

# 변동률
변동률 = 정책 후 산술평균 ÷ 정책 전 산술평균 − 1
```

| 규칙 | 값 | 이유 |
|---|---|---|
| 정책 전 | 2024-05-07 ~ 2025-06-27 (417일) | A/B 동일 기간 |
| 정책 후 | 2025-06-28 ~ 2026-08-18 (417일) | 첫 규제 시행일 기준 |
| 이상치 | `이상치여부 == False`만 사용 (158,586건) | 구 × 전용면적 20㎡ 구간 IQR 판정 |
| 평균 | **산술평균** (`Σ평단가 ÷ 건수`) | 아래 "산술 vs 가중" 참고 |
| 동 단위 최소 표본 | 정책 전·후 **각각 30건 이상** | 그 아래는 평균이 흔들림 |
| 미집계 월 | **2026-08 제외** | 신고 기간(계약 후 30일)이 남아 8건뿐 |
| 축 | **이중축 금지** | 평단가와 거래량은 위아래 패널로 분리 |

### 산술 vs 가중 — 산술평균을 쓰는 이유

가중평균은 **면적이 큰 거래에 자동으로 더 큰 가중치**를 줍니다.
정책 전후로 대형 평형(85㎡ 초과) 거래가 13.9% 줄어든 이번 분석에서는 그 가중치가 기간마다 달라져,
**가격 변화와 거래 구성 변화가 한 숫자에 섞입니다.** 그래서 건별 동등 가중(산술평균)을 씁니다.

두 방식이 결론을 바꾸지 않는지 확인했습니다 (이상치 제외 158,586건 기준).

| 항목 | 산술평균 | 가중평균 |
|---|---|---|
| 서울 정책 전 | 5,333.9 만원/평 | 5,453.8 만원/평 |
| 서울 정책 후 | 5,152.8 만원/평 | 5,174.3 만원/평 |
| 서울 전체 변동률 | **−3.39%** | −5.13% |

| 검증 항목 | 결과 |
|---|---|
| 구별 평단가 수준 상관 | r = 0.9988 (정책 전) / 0.9986 (정책 후) |
| 구별 변동률 상관 | r = 0.9818 |
| 구별 변동률 차이 | 평균 0.94%p · 최대 3.30%p (중랑구) |
| 상승/하락 부호가 뒤집히는 구 | **없음** |
| 순위 일치도 | 스피어만 0.97 · 최대 6계단 이동 |

- 부호가 뒤집히는 구가 없으므로 **"22곳 상승 / 3곳 하락"은 어느 방식으로 계산해도 같습니다.**
- 다만 순위는 최대 6계단 움직입니다. 랭킹을 인용할 때는 **"산술평균 기준"을 반드시 명시**합니다.
- 차이가 큰 구는 중랑(3.30%p) · 성동(2.48%p) · 구로(1.92%p) · 영등포(1.45%p) · 동작(1.18%p) 순입니다.
- 서울 전체 변동률은 두 방식 모두 음수지만 폭이 1.7%p 다릅니다. 애초에 서울 평균 한 줄만 쓰지 않는 것이 원칙입니다(한계 참고).


전처리 파이프라인 8단계와 business key 로직은 `README_pipelinepy.md` 참고.

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 배경 / 카드 / 사이드바 | `#F9F9F7` / `#FCFCFB` / `#F1F1EE` | 페이지 |
| 본문 / 보조 / 흐린 글자 | `#0B0B0B` / `#52514E` / `#898781` | 텍스트 |
| 테두리 | `#E1E0D9` | 카드·표 |
| 브랜드 | `#EB6834` | 로고, 정책 마커, 활성 상태 |
| 정책 전 / 후 | `#86B6EF` / `#1C5CAB` | 같은 지표의 두 기간 (같은 색 계열 명암) |
| 상승 / 하락 | `#D03B3B` / `#2A78D6` | 변동률 (국내 관행대로 상승=적, 하락=청) |
| 시리즈 1~5 | `#2A78D6` `#EB6834` `#1BAF7A` `#EDA100` `#E87BA4` | 카테고리 구분, 순서대로만 사용 |
| 감정 긍정 / 중립 / 부정 | `#1BAF7A` / `#C3C2B7` / `#E34948` | 감정 극성 |

- 폰트: Noto Sans KR (400 / 500 / 700). 큰 숫자는 700, 라벨은 500.
- 변동률 색은 **엔티티 기준**으로 고정 — 필터로 항목 수가 바뀌어도 색이 재배치되지 않게 합니다.
- 시리즈 색은 정해진 순서대로만 씁니다. 6개 이상이면 "기타"로 묶거나 화면을 나눕니다.

## 핵심 발견 (한 문단 요약)

25개 자치구 중 **22곳의 평단가가 상승**(중위 +7.1%)했고, 그중 **11곳은 거래량이 줄어드는 중에 올랐습니다.**
성동 −47.4% / +13.1%, 강남 −39.2% / +8.5%처럼 거래가 절반 가까이 빠지면서 단가만 오른 구간입니다.
반면 노도강·금관구는 거래량이 30% 이상 늘며 함께 올라, 진입 장벽이 낮은 외곽으로 수요가 옮겨간 풍선효과가 권역 단위에서 확인됩니다.
뉴스 여론은 부정 감정 27.5%로 4개 정부 중 가장 높습니다.
