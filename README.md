## 한 줄 결론

> 25개 자치구 중 **22곳의 평단가가 올랐고**(중위 +7.2%), 그중 **11곳은 거래량이 줄어드는 중에 올랐다.**
> 강남3구·마용성은 거래량이 33~38% 빠지며 가격이 올랐고, 노도강·금관구는 거래량이 29~36% 늘며 함께 올랐다.
> 진입 장벽이 낮은 외곽으로 수요가 옮겨간 풍선효과가 권역 단위에서 확인된다.

`서울 전체 평균` 한 줄만 인용하면 이 구조가 보이지 않는다. 이 앱은 항상 지역별 변동률을 함께 제시한다.

## 화면 구성

좌측 네비게이션(`st.navigation`)으로 4개 화면을 오간다. 첫 화면에서 결론을 먼저 보여주고, 근거를 확인하려는 사람이 아래 화면으로 내려가는 구조다.

### 1. 메인 대시보드 — `app.py`

| 섹션 | 파일 | 내용 |
|---|---|---|
| KPI 4개 | `sections/main/kpi.py` | 평균 평단가, 전체 거래 건수, 상승 자치구 수, 뉴스 부정 감정 비중 |
| 월별 평단가 + 거래량 | `monthly_trend.py` | 위 = 평단가 라인, 아래 = 거래건수 막대. **x축만 공유하고 y축은 분리** |
| 정책 마커 | `monthly_trend.py` | 6·27 · 9·7 · 10·15(2025) 3개 점선 |
| 4분면 매트릭스 | `quadrant.py` | 거래량 증감률(x) × 평단가 변동률(y), 색 = 권역, 좌상단 음영 |
| 4대 권역 비교 | `region_comparison.py` | 강남3구 / 마용성 / 노도강 / 금관구 |
| 정책에 대한 대중 반응 | `public_reaction.py` | 정책 × 관점별 감정 극성 |
| 보도 시점 분포 | `news_phase.py` | 시행전 / 시행일 / 초기반응 / 평시 |
| 감정 추이 | `sentiment_trend.py` | 시간축 감정 변화 |

### 2. 지역별 변동률 — `pages/1_지역별_변동률.py`

25개 자치구 다이버징 랭킹(`ranking_chart.py`), 자치구 타일맵(`tilemap.py`), 금액대별 거래 비중(`amount_band.py`), 법정동 상승 TOP 10 / 하위 10(`dong_tables.py`).

### 3. 정책 전·후 비교 — `pages/2_정책_전후_비교.py`

자치구 선택 → 전·후 KPI(`kpi.py`), 월별 추이(`monthly_chart.py`), 지표 요약표(`summary_table.py`), 전용면적별 거래량 변화(`area_compare.py`), 법정동 비교(`dong_compare.py`).

### 4. 뉴스·여론 분석 — `pages/3_뉴스_여론_분석.py`

관점별 감정 추이(`policy_polarity.py`), **감정별 기사 탐색 표**(`article_explorer.py`).

감정별 기사 탐색은 막대 클릭 토글 대신 **감정 탭(긍정/중립/부정) + 표** 방식이다. 토글은 한 번에 하나만 열려 감정 간 비교가 안 되고, 막대를 눌러야 한다는 사실이 발표 자리에서 드러나지 않는다. 표는 제목·시점·날짜·확률·원문 링크를 한 줄에 담을 수 있고 정렬·검색이 기본으로 붙는다.

## 계산 규칙 — 바꾸지 말고 쓴다

```
# 거래 한 건
평형   = 전용면적(㎡) ÷ 3.3058
평단가 = 거래금액(만원) ÷ 평형

# 그룹(구·동·월) 평균 — 두 방식
산술평균 = Σ(건별 평단가) ÷ 거래건수      ← 채택. 거래 한 건 = 1표
가중평균 = Σ(거래금액)   ÷ Σ(평형)        ← 검증용으로만 계산

# 변동률
변동률 = 정책 후 산술평균 ÷ 정책 전 산술평균 − 1
```

| 규칙 | 값 | 이유 |
|---|---|---|
| 정책 전 | 2024-05-07 ~ 2025-06-27 (417일) | A/B 동일 기간 |
| 정책 후 | 2025-06-28 ~ 2026-08-18 (417일) | 6·27 대책 시행일 기준 |
| 이상치 | `이상치여부 == False`만 사용 | 구 × 전용면적 20㎡ 구간 IQR 판정 |
| 평균 | **산술평균** | 아래 참고 |
| 최소 표본 | 구간별 **30건 이상**(`MIN_SAMPLE`) | 미달 시 '표본 부족' 표시 후 랭킹 제외 |
| 미집계 월 | **2026-08 제외** | 신고 기간(계약 후 30일)이 남아 있음 |
| 축 | **이중축 금지** | 평단가와 거래량은 위아래 패널로 분리 |

**산술평균을 쓰는 이유.** 가중평균은 면적이 큰 거래에 자동으로 더 큰 가중치를 준다. 정책 전후로 대형 평형 거래 비중이 달라진 이번 분석에서는 그 가중치가 기간마다 변해 **가격 변화와 거래 구성 변화가 한 숫자에 섞인다.**

두 방식이 결론을 바꾸지 않는지 확인했다 — 구별 변동률 상관 `r = 0.98`, 차이 평균 `0.94%p`(최대 3.30%p, 중랑구), **상승/하락 부호가 뒤집히는 구는 없다.** 다만 순위는 최대 6계단 움직이므로 랭킹을 인용할 때는 "산술평균 기준"을 명시한다.

### 감정 3그룹 매핑 (고정)

```
모델: dlckdfuf141/korean-emotion-kluebert-v2  (7종 감정)

긍정 = 행복
중립 = 중립 · 놀람          ← 놀람은 중립 (고정, 바꾸지 말 것)
부정 = 혐오 · 분노 · 슬픔 · 공포
```

당초 중립을 긍정에 합쳐 2그룹으로 단순화하려 했으나, 검증 문장 테스트에서 모델이 중립 문장을 '행복'과 혼동하는 것을 확인해 중립을 독립시켰다. 놀람은 가격 급등·급락을 전달하는 서술에 붙는 경우가 많아 방향성이 없다고 보고 중립에 포함한다. 이 매핑은 `News_Scraping.csv` 생성 단계에서 이미 적용돼 있어, 화면에서는 `lib/sentiment.py`가 3그룹 라벨을 그대로 쓴다.

## 주요 결과

### 권역별 (이상치·미집계월 제외)

| 권역 | 평단가 | 거래량 |
|---|---|---|
| 강남3구 (강남·서초·송파) | 8,727 → 9,149 **+4.8%** | 15,320 → 10,286 **−32.9%** |
| 마용성 (마포·용산·성동) | 6,401 → 6,968 **+8.9%** | 10,319 → 6,376 **−38.2%** |
| 노도강 (노원·도봉·강북) | 3,064 → 3,250 **+6.1%** | 8,800 → 12,000 **+36.4%** |
| 금관구 (금천·관악·구로) | 3,304 → 3,492 **+5.7%** | 6,205 → 7,988 **+28.7%** |
| 기타 13개 구 | 4,593 → 4,747 **+3.3%** | 41,051 → 39,687 **−3.3%** |

단위: 만원/평 · 건

### 여론 (기사 13,922건 · 감정 3그룹)

| 감정 | 건수 | 비율 |
|---|---|---|
| 중립 | 11,279 | 81.0% |
| 긍정 | 1,559 | 11.2% |
| 부정 | 1,084 | 7.8% |

정책 전후 전체 감정 비율은 **부정 4.7% → 8.2%로 약 1.7배** 늘었다(`News_Scraping_summary.csv`).

관점별로 보면 차이가 뚜렷하다. **시장 관점의 부정이 6·27에서 6.2% → 13.5%, 10·15에서 8.8% → 14.2%로 뛰는 반면, 기업 관점은 거의 변하지 않는다.** 같은 정책을 두고 시장 참여자와 기업의 반응이 갈린 것으로 읽을 수 있다.

## 배포

Streamlit은 세션 상태를 서버 프로세스에 들고 WebSocket을 유지하는 구조여서 **Vercel 같은 서버리스 플랫폼에는 맞지 않는다.**

권장 순서는 ① **Streamlit Community Cloud** — 이 리포가 organization 소유 private이라 GitHub `repo` OAuth 스코프에 대한 **조직 관리자 승인**이 필요하다. ② 승인이 어려우면 앱과 데이터만 담은 public 리포를 따로 만들어 배포. ③ **Hugging Face Spaces**(무료 CPU 티어, 유휴 시 슬립) 또는 Render / Railway.
